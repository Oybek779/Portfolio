Python Password Generator

A simple and secure password generator written in Python. Generates strong passwords using letters, numbers, and symbols.

Libraries Used

random, string

Code Example


import random
import string

def generate_password(length=16):
    chars = string.ascii_letters + string.digits + "!@#$%^&*()"
    return ''.join(random.choice(chars) for _ in range(length))

print(generate_password())
